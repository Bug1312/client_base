# Client Base
A Minecraft mod providing the player with a client-only room that dependencies can hook into for special functionality.

## Contributing
Pull requests are welcome, but:

- Please open an issue first to discuss what you would like to add/change/fix.
- Do not update version numbers in PRs. Versioning is managed by the release processes.
- When contributing, the `next` branch is preferred for changes/additions.
- If you wish to create multiple PRs for each port, that would be greatly appreciated.

Merged PRs may take time to appear in releases as all maintained ports recieve synchronized updates.
